Panduan Perintah Dasar Linux

Ringkasan perintah penting beserta penjelasannya untuk pengelolaan sistem Linux.

1. Navigasi dan Manajemen File

PerintahPenjelasan
pwdMenampilkan direktori (folder) aktif tempat Anda berada saat ini.
lsMenampilkan daftar file dan folder di direktori aktif.
cdBerpindah antar direktori (contoh: cd /folder/tujuan).
cd ..Naik satu tingkat ke direktori atau folder sebelumnya.
cd /Pindah langsung ke direktori utama (root directory) sistem.
mkdirMembuat folder baru (contoh: mkdir nama_folder).
touchMembuat file kosong baru (contoh: touch file.txt).
cpMenyalin file atau folder (contoh: cp file1.txt file2.txt).
mvMemindahkan atau mengganti nama file/folder (contoh: mv lama.txt baru.txt).
rmMenghapus file atau folder (gunakan opsi -rf untuk folder).

2. Membaca dan Mencari File

PerintahPenjelasan
catMenampilkan isi file teks secara keseluruhan di terminal.
lessMembaca isi file teks halaman demi halaman secara interaktif.
grepMencari kata atau pola tertentu di dalam file.

3. Manajemen Sistem dan Proses

PerintahPenjelasan
sudoMenjalankan perintah dengan hak akses administrator (superuser).
psMenampilkan daftar proses yang sedang berjalan di sistem.
top / htopMemantau penggunaan sumber daya sistem (CPU, RAM) secara real-time.
killMenghentikan proses berdasarkan nomor PID-nya (contoh: kill 1234).
dfMemeriksa kapasitas ruang kosong pada hard disk atau penyimpanan.
duMemeriksa ukuran penggunaan file atau folder dalam sistem.

4. Jaringan (Network)

PerintahPenjelasan
pingMenguji koneksi jaringan ke internet atau server lain (contoh: ping google.com).
curl / wgetMengunduh file atau melakukan permintaan data dari internet melalui terminal.
